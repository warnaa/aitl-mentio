# Typography

Use the system sans stack for interface prose. Use the retained monospace stack for code and filenames. These fonts are available locally through the operating system; there is no external font request. Sources: R01.2 and approved token table.

These role assignments were approved in stage 0 Q2; the sizes retain the existing Tailwind scale. Their CSS values live in the token source. The specimen below renders the role tokens rather than recreating a font scale inside Storybook.

Limit continuous prose to `--prose-max-width` (65ch); let code wrap or scroll within its own region rather than widening the screen. Do not truncate the mentee's saved question. Sources: approved Q2/Q3, booking spec UI/UX. Preserve readable content when users zoom; use semantic headings in order instead of selecting heading tags by appearance. Sources: WCAG 1.4.4, 1.4.10 and 1.3.1.
