# Shape and depth

Retain the existing radius scale: small 6 px, medium 8 px, large 10 px and extra-large 14 px. The default control uses medium; the existing Card uses extra-large. Source: stage 0 Q2 and approved token document retaining the existing shape scale.

Use `--divider-width` for the 1 px list separator. Surfaces are opaque; borders distinguish adjacent content. Sources: R01.3, A01.2, approved token table. Do not nest cards just to separate paragraphs; use section spacing and headings. Source: task What to avoid.

Keep the existing shadow scale. The existing small panel shadow and extra-small control shadow can add depth, but a boundary must remain understandable without the shadow. Do not add glow or glass effects. Sources: stage 0 Q2; task What to avoid; A01.2. Radius and shadow preservation does not mean that every component is already visually approved.

Focus has a different job from shape: it identifies the keyboard target. Keep it visible with the full semantic ring and neutral offset. Source: approved contrast correction, WCAG 2.4.7. The stage 2 component work applies this consistently.
