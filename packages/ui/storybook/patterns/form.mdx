# Form

Every panel and auth form is a `CrudForm` that submits through `apiCall`. Do not build a second form implementation. Sources: AGENTS.md; platform F4; accounts UI/UX.

## Rules

1. The label is always visible. A placeholder is only an example. Sources: task form pattern; WCAG 3.3.2.
2. A field is validated when it loses focus, and the whole form on submit, with the shared schema. Sources: task form pattern; platform F4.
3. After a failed submit, focus moves to the first error: a field, or the alert line when the error names no field. Sources: task form pattern; WCAG 3.3.1.
4. Entered values are kept after every failure. Sources: task form pattern.
5. A second submit is ignored while one is pending, and the button reads “Saving…”. Sources: task form pattern; platform F4.
6. Success is shown only after the server confirms. Sources: task form pattern.
7. Every required field has a message for a missing value in its schema. Sources: batch 3a verification (otherwise the validator's technical text is shown).
8. A network failure shows a fixed, actionable message and never the browser's text. Sources: platform F1.
9. Errors stay next to the form: no toast. Sources: task How to choose; reference R02.4.

## Code

```tsx
<CrudForm schema={registrationSchema} fields={fields} submitLabel="Create account"
  onSubmit={values => apiCall('/api/auth/register', { method: 'POST', body: values })}
  onSuccess={() => router.push(returnTo)} />
```
