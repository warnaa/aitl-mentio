# Earnings (preliminary)

A mentor sees what each session earned them and how it was calculated, without any suggestion that money has moved. Sources: E05-S01; R06, R21; D13, D14.

## Rules

1. Always show the calculation: price, minus Mentio's commission (with its rate), gives the share. Sources: R06.
2. Each earning uses the price and rate stored with its booking, so a later rate change does not rewrite history. Rows may show different prices for the same length. Sources: R21; book-and-pay `MentorEarning`.
3. Say why the session earned: held, mentee no-show, or late cancellation. Sessions that earned nothing do not appear. Sources: R10, R14; book-and-pay `reason`.
4. On the mock build, say that no money is paid out, and never show a payout date or balance to withdraw. Sources: D13, D14, R16.
5. The list stays within four columns on mobile; the commission per row is on the session's details. Sources: user decision 2026-10-31 (four columns); user decision 2026-11-01 (which columns).
6. Empty means “nothing earned yet”, and says what earns. Loading and failure use the shared feedback, never zeros. Sources: task empty-state rules.
