# Checkbox

## 1. Purpose

Let a person turn one independent choice on or off and see its current state. Sources: platform F4 `checkbox`; mentor-pages UI/UX.

## 2. When to use

Use it for the mentor's listing opt-in, “Show me in the mentor list”, on the mentor page editor. Use it for any future independent yes/no choice that takes effect when the form is saved. Sources: mentor-pages UI/UX Phase 4; D02 (share link plus opt-in list).

## 3. When not to use

Use RadioGroup or Select when the choices exclude each other, such as the session length. A setting that applies immediately would normally be a switch. Switch is deferred (see What is missing), so describe immediate effects in the hint instead. Do not use a checkbox to confirm a destructive action. Use the delete-confirmation pattern. Sources: approved stage-0 Q4 (Switch deferred); WAI-ARIA APG checkbox; task How to choose.

## 4. Anatomy

A 16 px box with a 1 px border and a 6 px radius. A check mark appears when the box is selected. A visible `Label` is required: clicking it toggles the box, and the label row supplies the 24 px target. An optional hint or error is linked with `aria-describedby`. Sources: user decision 2026-10-31 (16 px, radius-sm); WCAG 1.3.1, 2.5.8.

## 5. Variants

There is one variant. The `indeterminate` value of `checked` is supported by Radix and uses the same filled box. No current screen needs it, so it is not documented as a product state. Sources: package API; user decision 2026-10-31.

## 6. States

Default is an opaque box with the input border. Hover strengthens the border to the ring role. Focus shows the full 3 px ring with a 2 px offset. Selected fills the box with the primary role and shows a check mark, so the state is not carried by colour alone. Disabled lowers the opacity: the persistent hint says why, for example “Saving your listing choice.” Error sets `aria-invalid`, shows the destructive border and links a message. Loading is not a box state: block the box and say what is saving. Pressed is the click itself, with no separate appearance. Sources: task stage 2; WCAG 1.4.1, 2.4.7, 3.3.1; token contrast repairs; U02.1.

The hover and focus samples use documentation-only `data-preview-state` attributes, wired to the same declarations as the real pseudo-classes.

## 7. Behavior and accessibility

The box is a `button` with `role="checkbox"` and `aria-checked`. Tab reaches it, and Space toggles it. Enter does nothing on the box (Radix follows the WAI-ARIA checkbox pattern and prevents it), so it neither toggles the box nor submits the form. Clicking the label toggles the box and moves focus to it. A screen reader announces the label, “checkbox”, checked or not checked, and the linked hint. The box itself is 16 px. The 24 px target comes from the label row and the spacing exception: keep at least 8 px between neighbouring targets. Sources: WAI-ARIA APG checkbox; WCAG 2.1.1, 2.5.8, 4.1.2.

## 8. Content

Write the label as the outcome of a selected box, in the second person: “Show me in the mentor list”, not “Hide from list” or “Listing”. Put consequences in the hint: “Your page stays reachable through its share link either way.” Long labels wrap next to the box, aligned to its first line. Sources: U01.1; D02; mentor-pages UI/UX.

## 9. Responsiveness

At 320 px the label wraps and the box stays aligned with its first line. At 768 and 1440 px a checkbox row stays with its field group. Do not move the label away from the box. Sources: approved stage-0 Q3; WCAG 1.4.10.

## 11. Code

Minimal:

```tsx
import { Checkbox } from '@mentio/ui/components/checkbox';
import { Label } from '@mentio/ui/components/label';
<div className="flex items-center gap-within-group">
  <Checkbox id="isListed" name="isListed" />
  <Label htmlFor="isListed">Show me in the mentor list</Label>
</div>
```

Product composition with a hint:

```tsx
<div className="flex items-center gap-within-group">
  <Checkbox id="isListed" checked={isListed} onCheckedChange={value => setIsListed(value === true)} aria-describedby="isListed-hint" />
  <Label htmlFor="isListed">Show me in the mentor list</Label>
</div>
<p id="isListed-hint">Your page stays reachable through its share link either way.</p>
```

Sources: mentor-pages UI/UX; package API.

## 13. Related

RadioGroup handles exclusive choices. Switch is deferred. FormField supplies text-field anatomy, but a checkbox uses its own label row. Patterns: publication, where listing has an effect only on a published page; form. Sources: mentor-pages UI/UX; approved stage-0 inventory.
