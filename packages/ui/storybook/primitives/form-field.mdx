# FormField

## 1. Purpose

Keep a field name, requirement, hint and error connected to the same control. Source: task stage 2 minimum field anatomy; platform F4; accounts/mentor-pages/book-and-pay UI.

## 2. When to use

Use it for a public-work URL, rate, booking question and other fields that need the shared accessible anatomy. Source: task stage 2 minimum field anatomy; platform F4; accounts/mentor-pages/book-and-pay UI.

## 3. When not to use

Use CrudForm for schema-driven forms and submission; FormField does not replace it. Use Label plus a native control only when the full wrapper is unnecessary. It is not a fieldset for a radio/checkbox group. Sources: platform F4, approved component inventory and task How to choose requirements.

## 4. Anatomy

A wrapper, visible Label, Required/Optional marker, one native-compatible React control, optional description and optional error. The control receives a stable generated id unless an explicit id is supplied. Description and error remain linked together. The marker is visual; native required carries the requirement to assistive technology. Sources: package API, task field anatomy; WCAG 1.3.1/3.3.2.

## 5. Variants

One anatomy with optional/required, enabled/disabled, hint and error inputs. The child supplies Input or Textarea behavior. There are no success, compact or product-specific variants and no schema or network dependency. Sources: approved stage-0 Q2 and package API; no added variants are authorized.

## 6. States

The wrapper preserves the label and hint when an error appears. error sets aria-invalid and adds the error id; clearing it clears the wrapper error. Explicit wrapper required/disabled values take precedence, including false; otherwise the child value is retained. Read-only and loading belong to child native props. A disabled field must explain its unavailability in description. Selected/pressed are not wrapper states. Sources: task stage 2; WCAG 1.4.1/2.4.7/3.3.1; approved contrast corrections and U02.1.

The hover and focus previews use documentation-only data-preview-state attributes wired to the same declarations as real pseudo-classes. Sources: task stage 2 frozen-state requirement; approved Q2.

## 7. Behavior and accessibility

One child receives the id, required/disabled semantics and aria-describedby merged with any existing child references. The visible label names it; the hint and error describe it. Error text stays visible. The form decides when to validate, move focus and announce submission failure; this wrapper does not add an alert on every keystroke. Keep control targets at least 24 × 24 px. Sources: HTML native control semantics, WCAG 1.3.1/2.1.1/2.4.7/2.5.8/3.3.1/3.3.2/4.1.2.

## 8. Content

Use a specific noun label and a useful instruction in description. Errors say what failed and what to do. The default Required/Optional marker is English; requirementLabel can override the visible marker. No invented maximum label/hint length: keep copy concise and test long text. The consumer owns constraint values and translations. Sources: U01.1, task Content and longer-language requirements; task stage 2 minimum field anatomy; platform F4; accounts/mentor-pages/book-and-pay UI.

## 9. Responsiveness

At 320 px, label, marker, hint and error wrap within the field column; do not clip the control or messages. At 768 and 1440 px, preserve reading order and approved relationship spacing. Long descriptions stay within the shared prose limit. Sources: approved stage-0 Q2/Q3; WCAG 1.4.10.

## 11. Code

Minimal association:

```tsx
import { FormField } from '@mentio/ui/backend/forms';
import { Input } from '@mentio/ui/components/input';
<FormField label="Email address">
  <Input type="email" />
</FormField>
```

Product composition:

```tsx
import { FormField } from '@mentio/ui/backend/forms';
import { Input } from '@mentio/ui/components/input';
<FormField label="Public work URL" required
  description="Share a public repository or article."
  error="Enter a public URL beginning with http:// or https://.">
  <Input type="url" name="publicWorkLinks" />
</FormField>
```

The snippets compose real package components; import Input, Textarea and Label from their component subpaths and FormField from `@mentio/ui/backend/forms` when used. Sources: approved import contract; task stage 2 minimum field anatomy; platform F4; accounts/mentor-pages/book-and-pay UI.

## 12. Good and bad

<table><thead><tr><th>Good</th><th>Bad</th></tr></thead><tbody><tr><td>The public-work hint remains available with the URL error, and both ids describe the control.</td><td>Replacing the hint with an unlinked error makes the field harder to correct and loses supporting context.</td></tr></tbody></table>

The bad case is explained rather than rendered as an inaccessible interactive control. Sources: task good/bad and no-accessibility-violations requirements; WCAG 3.3.2/4.1.2.

## 13. Related

Input/Textarea own native editing. Label owns the name association. CrudForm owns parsed data, submission and server feedback; its existing implementation is adapted in the approved later pattern work, not silently replaced here. Sources: approved stage-0 component/pattern inventory, platform F4 and task How to choose.
