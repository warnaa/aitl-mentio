# EmptyState

## 1. Purpose

Explain why a place is empty and what the person can do next, instead of showing a blank area. Sources: task Content (empty states: why it is empty and the next step); existing `backend/feedback`.

## 2. When to use

- A list with no records yet: “You have no bookings yet” (`/rezerwacje`), “There are no mentors on the list yet” (`/mentorzy`), “You have no published slots” (`/mentor/terminy`).
- DataTable with zero rows.

Sources: book-and-pay UI/UX; mentor-pages UI/UX; existing DataTable.

## 3. When not to use

- When filters return nothing, use the “no results for these filters” state of the List with filters pattern, with a clear-filters action. Do not say “nothing here yet”.
- When loading failed, use ErrorMessage.
- When access is missing, use the detail view's not-found-or-no-access state.

Sources: task pattern requirements (separate empty and no-results states); approved stage-0 inventory.

## 4. Anatomy

The title (medium) explains what is missing. An optional description (muted, up to 65ch) explains when it will appear or why. An optional action, one Button or Link, gives the next step. Everything is centred with 40 px of vertical padding, by user decision. Sources: user decision 2026-10-31 (centred, a recorded exception to “everything centred”); retained base geometry.

## 5. Variants

There are no visual variants. Use the title only, title and description, or title, description and action. Sources: package API.

## 6. States

There is one static state. The action keeps Button or Link states. It has no hover, focus, selected, disabled or error appearance of its own. Sources: package API.

<Unstyled><Canvas of={Stories.States} /></Unstyled>

## 7. Behavior and accessibility

This is plain content in reading order. It is not a live region, because it replaces content once rather than announcing a change. The action is the only focusable element. Use a Link when it navigates (“Find a mentor”) and a Button when it acts (“Add a slot”). Sources: WCAG 1.3.2, 2.4.4, 4.1.2.

## 8. Content

- The title is what is missing, in the second person: “You have no bookings yet”.
- The description says when it will appear: “When you book a text session with a mentor, it appears here.”
- The action is a verb and object: “Find a mentor”, “Add a slot”.
- Do not use illustrations or emoji.

Sources: task Content; U01.1; references R02.5 and A01.3.

## 9. Responsiveness

The text wraps and stays centred at every width, with the description limited to 65ch. At 320 px the action stays a full-size target. Sources: approved stage-0 Q3; WCAG 1.4.10, 2.5.8.

## 11. Code

```tsx
import { EmptyState } from '@mentio/ui/backend/feedback';
<EmptyState title="You have no bookings yet"
  description="When you book a text session with a mentor, it appears here."
  action={<Button asChild><Link href="/mentorzy">Find a mentor</Link></Button>} />
```

Sources: book-and-pay UI/UX; package API.
