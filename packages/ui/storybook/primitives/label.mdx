# Label

## 1. Purpose

Give an editable control a persistent, accessible name. Source: accounts UI/UX; mentor-pages UI/UX; book-and-pay UI/UX.

## 2. When to use

Use it for account credentials, mentor public-work links, availability inputs and booking questions. Source: accounts UI/UX; mentor-pages UI/UX; book-and-pay UI/UX.

## 3. When not to use

Use a heading for a section and ordinary text for an explanation. Use FormField when you need the full label/hint/error/requirement composition; do not repeat that anatomy by hand. Sources: platform F4, approved component inventory and task How to choose requirements.

## 4. Anatomy

The installed Radix Label root with text and an htmlFor association to the real control. Requirement markers and help text belong to FormField, not a new Label variant. Sources: package API, task field anatomy; WCAG 1.3.1/3.3.2.

## 5. Variants

One label presentation: approved 14 px medium text with retained spacing. A long label wraps. Required, optional, loading and error are properties of the field; the Label does not invent independent variants for them. Sources: approved stage-0 Q2 and package API; no added variants are authorized.

## 6. States

A label remains readable in ordinary, hovered, focused-field, disabled and error contexts. It does not become selected or pressed and is not independently tabbable. Loading does not replace it. A disabled field needs a persistent explanation; dimming a label is not an explanation. Sources: task stage 2; WCAG 1.4.1/2.4.7/3.3.1; approved contrast corrections and U02.1.

The hover and focus previews use documentation-only data-preview-state attributes wired to the same declarations as real pseudo-classes. Sources: task stage 2 frozen-state requirement; approved Q2.

## 7. Behavior and accessibility

Set htmlFor to the control id. Clicking the label focuses an enabled text control, while Tab targets the control itself. Never give a label button semantics. Keep a default-height control as the pointer target; a short text line does not justify making the editable target smaller than 24 px. Sources: HTML native control semantics, WCAG 1.3.1/2.1.1/2.4.7/2.5.8/3.3.1/3.3.2/4.1.2.

## 8. Content

Use the name of the information requested: “Email address”, “Your question”, “Public work URL”. Keep instructions in a hint. There is no approved character cap: use concise copy, allow wrapping and verify a longer translation without truncation. Sources: U01.1, task Content and longer-language requirements; accounts UI/UX; mentor-pages UI/UX; book-and-pay UI/UX.

## 9. Responsiveness

At 320 px, allow multiple lines above the control. At 768 and 1440 px, keep the name next to its own control and preserve DOM reading order. Do not hide the label at a breakpoint. Sources: approved stage-0 Q2/Q3; WCAG 1.4.10.

## 11. Code

Minimal association:

```tsx
import { Label } from '@mentio/ui/components/label';
import { Input } from '@mentio/ui/components/input';
<Label htmlFor="email">Email address</Label>
<Input id="email" type="email" />
```

Product composition:

```tsx
import { FormField } from '@mentio/ui/backend/forms';
import { Input } from '@mentio/ui/components/input';
<FormField label="Public work URL" required
  description="Share a public repository or article.">
  <Input type="url" name="publicWorkLinks" />
</FormField>
```

The snippets compose real package components; import Input, Textarea and Label from their component subpaths and FormField from `@mentio/ui/backend/forms` when used. Sources: approved import contract; accounts UI/UX; mentor-pages UI/UX; book-and-pay UI/UX.

## 12. Good and bad

<table><thead><tr><th>Good</th><th>Bad</th></tr></thead><tbody><tr><td>Label with htmlFor matching the unique field id: clicking it focuses that field.</td><td>Nearby text with no association, or a placeholder used as the only name: proximity does not provide a reliable accessible label.</td></tr></tbody></table>

The bad case is explained rather than rendered as an inaccessible interactive control. Sources: task good/bad and no-accessibility-violations requirements; WCAG 3.3.2/4.1.2.

## 13. Related

FormField composes the Label with messages and requirement text. A section heading groups content; it does not name a control. Tooltip must not carry the only label. Sources: approved stage-0 component/pattern inventory, platform F4 and task How to choose.
