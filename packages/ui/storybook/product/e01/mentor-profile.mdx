# MentorProfile

## 1. Purpose

Show a mentee what the mentor has done and what a session costs and when, so they can decide whether to book. Sources: E01-S01 to S03; D02 (share link is the main entry); N02 (public work is the trust signal).

## 2. When to use

Use it as the body of the public mentor page, `/mentorzy/<slug>`. In E02 its slots become “Book” links. Sources: mentor-pages UI/UX; book-and-pay UI/UX.

## 3. When not to use

For the mentor's own editor, use the My page screen with CrudForm. For the list, use MentorDirectory. Never show ratings, stars or reviews. Sources: N02; mentor-pages UI/UX.

## 4. Anatomy

In the spec's order:
1. The name (`h1`).
2. The description, plain text with line breaks kept.
3. “Public work” links (open in a new tab).
4. Prices, or the unavailable text.
5. Available slots grouped by day.
6. The text-only line.

Sources: mentor-pages UI/UX; N01.

## 5. Variants

There are no visual variants. Slots are plain text (E01), or links when `href` is given (E02). Sources: mentor-pages and book-and-pay UI/UX.

## 6. States

- **Priced with slots.**
- **No rate:** “The mentor has not set a rate yet — booking is unavailable”. Slots stay visible but are not bookable.
- **No slots.**

A draft or unknown page is a 404 from the app. Errors go to the app's error boundary. Links have Link states. Sources: mentor-pages UI/UX; R03; platform F2.

## 7. Behavior and accessibility

It is an `article` named by the `h1`, with `h2` sections and an `h3` per day. Work links use `target="_blank"` and `rel="noopener noreferrer nofollow ugc"`, with a visually hidden “opens in a new tab”. Booking links include the day for screen readers. It is server-safe. Sources: mentor-pages UI/UX; WCAG 1.3.1, 2.4.4, 3.2.5.

## 8. Content

Everything comes through props:
- The URL string is the visible text of each work link (in the code role, allowed to break).
- Prices are written like “25 min — 120 zł”.
- Days and times are in Warsaw time.
- The text-only line comes from N01.

Sources: mentor-pages UI/UX; reference R01.2; user decisions 2026-10-31.

## 9. Responsiveness

Prose stops at 65ch. At 320 px long URLs break anywhere, and slot times wrap within each day. Sources: approved stage-0 Q3; WCAG 1.4.10.

## 11. Code

```tsx
import { MentorProfile } from '@mentio/ui/components/mentors/MentorProfile';
<MentorProfile displayName={page.displayName} description={page.description}
  work={{ heading: 'Publiczna praca', links: page.publicWorkLinks, newTabLabel: 'otwiera się w nowej karcie' }}
  prices={{ heading: 'Ceny', items: page.prices && [`25 min — ${formatMoney(page.prices.min25)}`, `50 min — ${formatMoney(page.prices.min50)}`], unavailableText: 'Mentor nie ustalił jeszcze stawki — rezerwacja jest niedostępna' }}
  slots={{ heading: 'Wolne terminy', days: groupByDay(page.availableSlots), emptyText: 'Brak wolnych terminów' }}
  textOnlyNote="Sesje odbywają się wyłącznie tekstowo" />
```

Sources: mentor-pages UI/UX. `groupByDay` belongs to the app (F7 formatting).
