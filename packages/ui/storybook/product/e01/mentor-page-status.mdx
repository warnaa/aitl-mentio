# MentorPageStatus

## 1. Purpose

Show the mentor whether their page is public, let them publish or unpublish it, and give them the share link to send to mentees. Sources: E01-S01; D02; mentor-pages UI/UX (`/mentor/strona` status card).

## 2. When to use

Use it at the top of the mentor's page editor. Sources: mentor-pages UI/UX.

## 3. When not to use

For the public page, use MentorProfile. For page content, use the editor's CrudForm. Sources: mentor-pages UI/UX.

## 4. Anatomy

- A Card whose heading carries a StatusBadge (Draft or Published).
- The publish/unpublish ActionButton, composed by the app.
- A read-only “Share link” field that selects itself on focus.
- “Copy link”, with polite local feedback.
- “View page” when published.

Sources: mentor-pages UI/UX; platform F5 and F6.

## 5. Variants

There are no visual variants. The state comes from props: draft or published, and `view` present or not. Sources: package API.

## 6. States

- **Draft:** publish is available.
- **Draft with unsaved changes:** publish is disabled, with “Save your changes before publishing.”
- **Published:** unpublish and view are available.
- **Copy:** “Copied” is announced; if copying fails, “Select the link and copy it manually”.

Publish failures appear inline, and their field errors go to the editor (F4 `externalFieldErrors`). Sources: mentor-pages UI/UX; platform F4 and F5.

## 7. Behavior and accessibility

The copy result is a `role="status"` region, which the spec asks for (“Skopiowano”, polite). The share field has a visible label. The action has ActionButton's keyboard and focus behavior. Sources: mentor-pages UI/UX accessibility; WCAG 4.1.3.

## 8. Content

Use the status words “Draft” and “Published”. The share URL is absolute. Action labels are a verb and object. All text comes through props. Sources: mentor-pages UI/UX; user decision 2026-10-31.

## 9. Responsiveness

The share field fills the card width. Actions wrap at 320 px. Sources: WCAG 1.4.10.

## 11. Code

```tsx
<MentorPageStatus heading="Twoja strona" statusLabel="Opublikowana" statusTone="success" shareLabel="Link do udostępnienia"
  shareUrl={absoluteUrl(page.shareUrlPath)} copyLabel="Kopiuj link" copiedLabel="Skopiowano" copyFailedLabel="Zaznacz link i skopiuj go ręcznie"
  view={{ href: page.shareUrlPath, label: 'Zobacz stronę' }} action={<ActionButton label="Wycofaj publikację" run={unpublish} onSuccess={router.refresh} />} />
```

Sources: mentor-pages UI/UX.
