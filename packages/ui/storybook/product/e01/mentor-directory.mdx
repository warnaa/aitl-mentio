# MentorDirectory

## 1. Purpose

Let a mentee compare published, listed mentors quickly and open the one whose work fits their problem. Sources: E01-S04; mentor-pages UI/UX (`/mentorzy`); reference R01.1.

## 2. When to use

Use it as the body of the public mentor list, `/mentorzy`, with `?strona=N` paging (20 per page). Sources: mentor-pages UI/UX.

## 3. When not to use

- For panel tables, such as a mentor's own slots, use DataTable.
- For one mentor, use MentorProfile.
- Never sort or badge mentors by ratings.

Sources: N02; references A03.1 and A03.3.

## 4. Anatomy

- The page heading and an optional intro.
- A list of rows, each with the name as a link, a description excerpt and two formatted facts: the 25-minute price or “No rate yet”, and the next bookable slot or “No slots to book”.
- Optional page links.

Rows are separated by thin lines. Sources: mentor-pages UI/UX; references R01.1 and R01.3; ten-line decision 2.

## 5. Variants

There are no visual variants. Optional parts: intro, pagination and `linkComponent`. Sources: package API.

## 6. States

- **Results.**
- **Partial data:** no rate or no slot. The facts say so in words, and an unpriced mentor is never shown as bookable.
- **Empty:** “There are no mentors on the list yet.”
- **Many results:** paged.

Loading and errors happen on the server: the page renders complete or the app's error boundary handles it (F2). Hover and focus are the Link states. Sources: mentor-pages UI/UX; platform F2.

Also see these stories: **Empty** (no listed mentors); **Partial Data** (no rate and no slots shown as text).

## 7. Behavior and accessibility

It uses a section named by its `h1`, a `ul` of rows, and an `h2` link per mentor, so heading navigation lists the mentors. Pagination is a named `nav` with `rel="prev"` and `rel="next"`. It is server-safe, with no client JS. Sources: WCAG 1.3.1, 2.4.4, 2.4.6; stage-3 decision 1.

## 8. Content

All text and formatted values come through props: prices in “zł”, slot times in Warsaw time, and an excerpt of the first 200 characters. Missing data is written out (“No rate yet”), never left blank. Sources: user decisions 2026-10-31 (copy through props, zł); mentor-pages UI/UX.

## 9. Responsiveness

Rows fill the content width up to 1152 px, and excerpts stop at 65ch. At 320 px the facts wrap under each other and long names break. Sources: approved stage-0 Q3; WCAG 1.4.10.

Also see these stories: **Long Content** (long names and excerpts).
The 320 px rendering is the **Narrow** story in the sidebar. It is not embedded here: a docs page renders every example at the page’s own width, so it would look the same as the examples above. Source: verification 2026-11-01 (axe best-practice).

## 11. Code

```tsx
import { MentorDirectory } from '@mentio/ui/components/mentors/MentorDirectory';
<MentorDirectory heading="Mentorzy" emptyText="Na liście nie ma jeszcze mentorów" linkComponent={Link}
  items={page.items.map(item => ({ href: `/mentorzy/${item.slug}`, displayName: item.displayName, excerpt: item.descriptionExcerpt,
    priceLabel: item.price25 ? `25 min — ${formatMoney(item.price25)}` : 'brak stawki',
    availabilityLabel: item.nextBookableStartsAt ? formatSlotTime(item.nextBookableStartsAt) : 'brak terminów do rezerwacji' }))} />
```

Sources: mentor-pages UI/UX (Polish copy in the app, F1/F7).
