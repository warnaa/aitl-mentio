# E04 — screens and states (preliminary)

E04 has no screen specification (approved stage-0 Q4). The session room follows:
- E04-S01/S02, R01, R02, R09, R10, D16 and N01;
- references R02.1–R02.6: the conversation is the main area, with replies to a specific message, author and time, no extra pop-ups, no decorative emoji, and focused navigation;
- approved Q3: details after the conversation on narrow screens, beside it from Tailwind `xl` (the breakpoint: user decision 2026-11-01);
- approved Q5: inline quoted replies.

Each state is a story under **Product › E04 › Screens**.

**Decided by the user on 2026-11-01** (POSTEP 9, 10, 12, 13), except the notice texts, which stay a **Proposal** until the E04 spec:
- one route `/sesje/[id]` for both participants;
- `POST /api/bookings/[id]/messages` with `{ body, replyToId }`;
- the 409 code `session_ended`;
- no writing before the start, and a read-only transcript after the end;
- the backtick code format and Ctrl+Enter to send;
- no optimistic messages;
- the notice texts.
