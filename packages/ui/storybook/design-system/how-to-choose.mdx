# How to choose

When two components seem to fit, find your situation in the left column. Each row gives a Mentio example and its source. Components marked “not in the system” are on What is missing: do not build them ad hoc (Contributing).

## Button, link, icon button or action menu

<table className="ds-table"><thead><tr><th>If…</th><th>Use</th><th>Product example</th><th>Source</th></tr></thead><tbody><tr><td data-label="If…">It performs an action on this page (save, pay, publish)</td><td data-label="Use">Button; ActionButton when it calls the API</td><td data-label="Product example">“Pay 240 zł”, “Publish page”</td><td data-label="Source">R01.5; platform F5</td></tr><tr><td data-label="If…">It goes somewhere (another screen, public work, a booking)</td><td data-label="Use">Link (an anchor, never <code>href="#"</code>)</td><td data-label="Product example">“View booking”, a mentor's public work</td><td data-label="Source">WCAG 2.4.4; native link semantics</td></tr><tr><td data-label="If…">It needs button emphasis but navigates</td><td data-label="Use">Button <code>asChild</code> with a real anchor</td><td data-label="Product example">“Book” on a slot</td><td data-label="Source">Button docs; WAI-ARIA button vs link</td></tr><tr><td data-label="If…">It is a familiar, repeated action with no room for text</td><td data-label="Use">Icon button with an accessible name and a Tooltip</td><td data-label="Product example">Copy the share link</td><td data-label="Source">WAI-ARIA APG tooltip; WCAG 4.1.2</td></tr><tr><td data-label="If…">One object has several secondary actions</td><td data-label="Use">DropdownMenu; the main action stays a visible Button</td><td data-label="Product example">Copy share link, view public page, unpublish</td><td data-label="Source">R01.5; user decision 2026-10-31</td></tr><tr><td data-label="If…">It is the main action of the view</td><td data-label="Use">A filled primary Button, never inside a menu</td><td data-label="Product example">“Accept question”</td><td data-label="Source">R01.5</td></tr></tbody></table>
