# Components

Every component in `@mentio/ui`, with a small working preview, its group, one sentence on what it is for, and a link to its documentation page. The previews are the real package components with example data from the brief and specs.

- **Primitives** are shadcn/Radix components adapted to Mentio's tokens.
- **The shared panel layer** (`@mentio/ui/backend/*`) carries API calls, forms, lists, actions and feedback, so screens never re-implement them.
- **Product components** belong to one concept and group by epic.

Sources: AGENTS.md (reusable API and UI layer; one designated home per component); approved stage-0 inventory.

Page-level components (PanelShell, AccountNav, AuthPanel, MentorDirectory, MentorProfile) own the page's landmarks. Their previews are inert thumbnails: visible, but kept out of the accessibility tree and tab order, so this page stays one valid document. Open their pages for working examples. Source: verification 2026-11-01 (axe landmark rules).

Overlays (Dialog, AlertDialog, DropdownMenu, Popover, Tooltip) are shown closed; their triggers open them here.
