# Mentio foundations

Readable, warm, focused. Build with the approved semantic roles and verify every state in both themes. Sources: R01.1–R01.5, R02.1–R02.6, U01.1/U02.1 and approved stage-0 decisions Q1–Q5.

This is stage 1. Foundations are available; component adaptation and the full usage handbook follow in stages 2–4. Existing package components may still contain legacy styles. They are reported by `npm run check:tokens`; they have not been certified as compliant.

## Start with foundations

Use Color, Typography, Spacing and layout, Shape and depth, Motion, Icons and Themes. Every page identifies its sources. All examples use English; currency remains PLN, displayed as “zł” after the amount (user decision 2026-10-31), and time remains Europe/Warsaw. Sources: task language instruction; brief D10/R08 and approved stage-0 scope.

## Technical note

The implementation reuses the existing shadcn/ui New York components, Radix behavior and Lucide icons inside `@mentio/ui`. This is provenance, not the product's visual identity. Storybook 10.6.5 uses React/Vite in this standalone package; no Next route files or server services are imported.

## Commands

- `npm run storybook`: local documentation on port 6006.
- `npm run build-storybook`: static documentation under `packages/ui/storybook-static`.
- `npm run test:storybook`: all executable stories in light and dark, including interaction and failing accessibility checks.
- `npm run check:tokens`: report literal colors, palette classes and arbitrary Tailwind values outside the token source; existing violations will fail until stage 2 fixes them.

Source: approved stage-0 technical plan; task stages 1 and 2.
