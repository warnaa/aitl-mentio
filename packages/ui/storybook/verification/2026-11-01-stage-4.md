## Problems found and fixed

1. **Dark-mode contrast in the catalog:** Storybook's docs styles reach a table nested in a docs table, even under Unstyled (text colour, striped rows). The fix is scoped to the preview cells.
2. **MDX parsing:** `*` inside JSX table cells started emphasis and broke indexing. Asterisks are now escaped, and bold is written as `<strong>`.
3. **Token checker on prose:** literal forbidden-class examples failed `check:tokens`. The pages now describe those forms in words; the checker was not weakened.
4. **Ordered lists had no numbers** across docs (steps, numbered pattern rules). Numbers are restored.
5. **Docs tables at 320 px** squeezed to a few letters per line. Below 48rem they now stack, with column names.
6. **Component names wrapped mid-word.** Name columns no longer wrap.
7. **PanelShell thumbnail** squeezed its content into a vertical strip; it now gets its layout's width.
