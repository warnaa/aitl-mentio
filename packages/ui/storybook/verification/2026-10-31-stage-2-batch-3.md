## Problems found and fixed during verification

1. **Popover panels had no accessible name** (`aria-dialog-name`). The panel has `role="dialog"`, and the base `PopoverTitle` is not linked to it. The rule now documented and applied: `aria-labelledby` to the title id, or `aria-label`.
2. **Long menus left the 320 px viewport** (623 px). `max-inline-size` now uses Radix's available width, and items wrap.
3. **Long popover trigger overflowed by 5 px.** A nowrap link Button now uses the documented long-label classes.
4. **A dialog's header could run under the close button.** The header leaves room for it, and an assertion checks the header's content box.
5. **Nested docs story frames reset the docs theme.** I tried `docs.story.inline: false` to show open modals on docs pages, but the nested preview broadcasts its own globals, which switched the whole docs page to light. The attempt was reverted, and no nested frames are used.
6. Play functions of interactive stories are not embedded in docs, because they would open overlays on the docs page. Typographic quotes in story text fix lint.

## Findings for decision (not changed)

- **Radix closes a tooltip on scroll, including the scroll caused by focusing an off-screen trigger.** On a 300 px tall viewport, tabbing to the trigger scrolled the page and the tooltip closed at once. It stays open when the trigger is already visible, and pressing Tab again shows it. This conflicts with the persistence rule in WCAG 1.4.13. Impact is limited because Mentio tooltips only repeat a visible or accessible name. A fix would change component behavior.
