## Problems found and fixed

1. **ActionButton confirmation lost focus** after closing, because Radix returns focus only to its own trigger. Fixed with `onCloseAutoFocus`, with a unit assertion and a keyboard story.
2. **Empty required fields showed Zod's technical text** (“Invalid input: expected string, received undefined”). Story schemas now give a missing-value message, and the rule is documented on CrudForm and the Form pattern.
3. **The network error leaked the browser's message.** Fixed as in F1.
4. **ActionButton with a long label overflowed 320 px by 271 px.** It wraps now; a regression story fails without the fix (verified).
5. **PanelShell's first breakpoint contradicted Q3** (sidebar at 768). Moved to `lg`.
6. **CrudForm set state synchronously inside effects** (react-hooks lint). Refreshed values are now adopted by adjusting state during render, and the focus target is a ref.
7. **MDX rejected multi-line JSX tables again.** All tables are now single blocks.
8. **The filter's options came from the visible rows.** They now come from all known statuses.
9. **Test-harness artefacts:** activating the skip link navigated the test frame; my 3a script waited for network idle on a never-resolving story. Both were adjusted; no product code changed.
