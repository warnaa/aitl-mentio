## Problems found and fixed

1. **Heading levels:** with a page-level title (h1), the question heading was h3 and skipped a level (axe). It is now derived from the title level, with a unit test.
2. **A long status next to the title overflowed 320 px by 84 px.** Statuses in card headings now wrap. The regression story fails without the fix (verified).
3. **The select placeholder and its error had identical text** (“Choose 25 or 50 minutes”), so the error repeated what was already on screen. The placeholder is now “Select a length”. The same pattern was fixed in the Select and CrudForm stories, and the rule was added to the Select page.
4. **Non-story exports in a stories file were indexed as stories.** The shared data moved to `fixtures/bookings.ts`.
