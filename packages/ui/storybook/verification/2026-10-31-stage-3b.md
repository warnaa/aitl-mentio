## Problems found and fixed

1. **Wrong slot-removal contract in 3a's stories** (`/slots/:id` instead of `DELETE /api/availability/slots?id=`). Corrected in the stories and the ActionButton code sample.
2. **The status card's share text used `aria-labelledby` on a `<p>`**, which is not allowed. It is now a labelled read-only field that selects itself on focus.
3. **The compact PanelShell navigation's current marker** was a left bar that looked like a bracket in a horizontal row. It is now a bar under the item in the compact row and a left bar in the sidebar.
4. **The no-ratings test matched “accessibility reviews”** in a description (a false alarm). It now checks only real rating signals.
5. **A name clash between a story export and a composition** broke indexing. Renamed.
