## Remaining work and limits

- **Separate-session agent test:** not performed, as stage 5.5 requires. The
  proposed Users screen, source contracts, prompt and evaluation criteria are
  in POSTEP.md. The screen is absent from Storybook; no test implementation was
  produced here. Every guess discovered there must be resolved in docs or tracked
  in What is missing before calling the complete design system finished.
- **Open decisions:** interpretations 1–8 recorded in POSTEP (some overlap with
  later approvals); E04 notice wording and about-80-character reply excerpts.
  Continuation does not approve these implicitly.
- **Accepted limitations:** Radix Tooltip closes when scrolling focuses an
  offscreen trigger (persistence part of WCAG 1.4.13); tooltips only repeat names.
  The approved system font stack can fall back to an emoji font for digits on
  this Linux host; the screenshots show this. No font/style change made.
- **Axe exception:** only Select/Open disables `aria-hidden-focus`: Radix hides
  its trigger behind the modal listbox and keeps focus in the list. Its separate
  keyboard tests check that focus cannot reach the hidden trigger. See the source
  comment and Select documentation. No new exception added.
- **Not checked:** human screen-reader use, physical touch devices, Safari and
  Firefox. Axe and keyboard evidence is Chromium automation, not full WCAG
  certification or product authorization testing.
- **Product gaps:** E03–E05 still lack dedicated specs; E06 parked; Switch, Avatar,
  Tabs, Toast, Combobox, Sheet/date picker deferred. Error/404 pages, operator
  invitation/dispute screens, notification UI, message transport/limits/editing,
  real payouts, Polish product copy/formatting and admin-shell migration remain
  tracked in What is missing. No application functionality was implemented.

No new design direction is proposed. The Users screen is a **proposed test
selection**, not an approval to redesign the admin. The spec stays active until
the separate-session test and its documentation follow-up are complete.
