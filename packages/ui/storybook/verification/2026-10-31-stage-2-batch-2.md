## Problems found and fixed during verification

1. **Card header overflow at 320 px (WCAG 1.4.10).** A nowrap header action widened the card by 61 px. Fix: a `card-header` container query below 24rem (the value of Tailwind's `--container-sm`) moves the action under the title. A container cannot restyle itself, so the header's children span both columns instead. The regression story `NarrowHeaderReflow` fails without the fix (verified) and passes with it.
2. **Invalid nesting.** The Separator stories put a `div` separator inside `<p>`. The built-page console check caught it, and the stories now use a `div` row.
3. **Flaky Select keyboard test (about 25% of full runs).** Instrumentation showed the list opened and then closed on a late `resize` event: the preceding Narrow story restores the iframe width asynchronously, and Radix Select closes on window resize by design. Disabling file parallelism did not help; it made the failure rate worse. Fix: wait until the viewport has been stable for 250 ms before opening. The Tab-based focus is kept.
4. **FormField with Select.** FormField clones its child, but the `Select` root renders no element. The documented and tested composition wraps `SelectTrigger` inside the `Select`.

## Findings for decision (not changed)

- **Digits rendered by an emoji font on some Linux systems.** Tailwind's default `--font-sans`, retained by approval, lists “Noto Sans”. Where it is missing but Noto Color Emoji exists, Chromium renders digits with the emoji font. Here, CDP reports `card-title` “128” → Noto Color Emoji, and the glyphs are grey and offset. This predates the batch. A fix would change the approved font stack, so it needs a decision.
